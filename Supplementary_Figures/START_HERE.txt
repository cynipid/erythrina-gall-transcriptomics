Supplementary figure package
Original package: 17 October 2026
Final review update: 26 October 2026 (comment 26)

Final numbering: Supplementary Figures S1-S8. Figure_Index.tsv lists every PDF,
PNG, script and source table. All individual figure PDFs, PNGs, plotting scripts
and frozen inputs are byte-identical to the supplied baseline (55 non-caption
files). No plot, coefficient, classification or sample label was changed.

The nine-page EGW_Supplementary_Figures_S1-S8.pdf was regenerated with imported
artwork explicitly clipped and placed below headings/captions. Every page was
visually checked, including the reported pages 4, 5, 7 and 8. Export_Audit.json
records the current checks. Older audit records retain the original production
and source-extraction provenance.

captions.json is the canonical caption source. The S3/S4/S7/S8 captions include
the previously approved estimated, unshrunk fold-change criterion wording.
The eight caption.txt files, Supplementary_Figure_Captions.txt and the Word file
are synchronized. Species/statistical P italics and log subscripts are preserved.

To rebuild captions and the combined preview:
    python -m pip install -r requirements.txt
    python build_captions.py
    python build_preview.py
To rebuild individual figures in another output directory:
    python rebuild_all.py --outdir rebuilt_figures

S2 and S6 retain their portable correlation-heatmap layouts and frozen matrices.
The optional S2 RDS source-extraction script uses rdata 1.1.0; ordinary plotting
reads the supplied source matrix and requires no RDS conversion or model fit.
No statistical, alignment, annotation or prediction analysis was rerun.
SHA256SUMS.txt identifies the distributed files; PDF metadata can differ on rebuild.
